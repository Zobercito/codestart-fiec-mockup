De la idea al programa

Escribir un programa no es solo escribir texto: es darle una instrucción precisa a la máquina. Cuando ejecutas un programa, el computador recorre una secuencia ordenada de pasos. Entender ese recorrido es la diferencia entre memorizar sintaxis y comprender qué hace el código.

💡 Analogía cotidiana

Un programa es como una receta de cocina: la receta es el código, el cocinero es el procesador y los ingredientes que va tomando de la nevera son los datos que guarda en la memoria.

Anatomía de un programa

hola_mundo.c

Pasa el cursor sobre cada línea para descubrir qué hace.

1 #include <stdio.h>
2 int main() {
3 printf("Hola Mundo");
4 return 0;
5 }

* Lenguaje de ejemplo (C) — el definitivo lo define el docente del propedéutico (secc. 15.3).

1
Biblioteca estándar stdio.h

Le indica al programa que existe una herramienta para imprimir texto en pantalla. Sin ella, el procesador no sabría qué significa printf.

2
Función principal int main()

Es el punto de entrada: el programa siempre empieza a ejecutarse aquí. int indica que la función devolverá un número entero.

3
Salida estándar printf(...)
← línea activa (hover)

Muestra el texto entre comillas en la pantalla. Las comillas son obligatorias: marcan que es texto y no un nombre de variable.

4
Tipo de retorno return 0;

Termina la función principal y devuelve 0 como señal de que todo salió bien. Otra señal sería un número de error.

5
Llave de cierre { }

Las llaves delimitan el bloque de la función. Si olvidas cerrarla, el programa no compila.

Clasifica la edad con un condicional

Completa el programa para que imprima "Mayor de edad" si la edad es igual o mayor que 18, y "Menor de edad" en cualquier otro caso.

Ejemplo
Entrada: edad = 20 → "Mayor de edad"
Entrada: edad = 15 → "Menor de edad"
Casos de prueba
✓ edad = 20 → aprobado
✕ edad = 18 → falló (esperaba "Mayor")
○ edad = 15 → pendiente
💡 Pista 1 · Abierta ya revelada

Recuerda que el lenguaje compara con >= cuando quieres incluir el número en el rango. Con solo > el 18 quedaría fuera.

🔒 Pista 2 · Revelar −10 pts

Muestra una pista más específica.

Línea 6 · Lógica La salida no coincide con lo esperado

Tu programa imprimió "Mayor de edad" pero el caso de prueba espera ese texto con edad = 18. Con el operador >, el 18 queda excluido y tu programa responde "Menor de edad".

esperado
edad = 18 → "Mayor de edad"
obtenido
edad = 18 → "Menor de edad"
Caso 1 aprobado Salida correcta

Así se ve el estado cuando la solución pasa todos los casos: tarjeta verde, mensaje de acierto y botón de siguiente reto.
